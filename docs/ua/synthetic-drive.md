# Синтетична поїздка

`include/sensor_fusion/sim/synthetic_drive.h` вигадує поїздку і заповнює нею `Scenario`. Справжній шлях відомий точно, тож похибку фільтра можна виміряти відносно нього. Записи та їхні правила описано в [типах 2D-сценарію](ekf-scenario.md).

```cpp
const std::optional<Scenario> drive =
    GenerateScenario(DemoDrive(), SyntheticConfig{});
```

## Сегменти

Поїздка — це список `DriveSegment`. Усередині сегмента прискорення і кутова швидкість сталі.

| Поле | Зміст |
| --- | --- |
| `duration` | Секунди, ціла кількість кроків IMU |
| `accel` | Прискорення вперед, м/с² |
| `yaw_rate` | Рад/с. Додатне значення повертає ліворуч |

Генератор не перевіряє, чи рух реалістичний. Сегмент може повертати машину за нульової швидкості.

## Налаштування

`SyntheticConfig` тримає часові параметри, похибки датчиків і seed.

| Поле | Типове значення | Зміст |
| --- | --- | --- |
| `imu_dt` | 0.01 | Секунди між кроками IMU |
| `start_yaw`, `start_speed` | 0, 0 | Курс (рад) і швидкість (м/с) у `t = 0` |
| `gnss_period` | 1.0 | Секунди між фіксами |
| `gnss_offset` | 0.5 | Час першого фіксу, с |
| `outage_start` | 25.0 | Початок втрати сигналу, с |
| `outage_duration` | 15.0 | Тривалість втрати, с. 0 вимикає її |
| `accel_noise`, `accel_bias` | 0.05, 0.02 | м/с² |
| `gyro_noise`, `gyro_bias` | 0.005, 0.002 | Рад/с |
| `gnss_noise` | 2.0 | Метри, на схід і на північ |
| `seed` | 1 | Seed шуму |

Шум — це стандартне відхилення одного зразка. Зміщення однакове для кожного зразка датчика. Значення шуму не залежать від `imu_dt`.

## Справжній шлях

Машина стартує в `(0, 0)` зі `start_yaw` і `start_speed`. Один крок рахується методом середньої точки:

```text
v_mid   = v   + accel * dt / 2
yaw_mid = yaw + yaw_rate * dt / 2
east   += v_mid * cos(yaw_mid) * dt
north  += v_mid * sin(yaw_mid) * dt
yaw    += yaw_rate * dt
v      += accel * dt
```

Якщо не рахувати округлення, метод точний на прямій зі сталим прискоренням. На повороті зі сталою швидкістю крок довший за справжню хорду приблизно на `(yaw_rate * dt)² / 24` своєї довжини. `yaw` не зводиться до проміжку.

`N` кроків дають `N + 1` зразок в `imu` і в `reference`. Час — це `i * dt`, тож він не накопичує округлень.

## IMU

`imu[i]` — це вхід сегмента в момент `t[i]` плюс зміщення і шум. Він переводить стан із `t[i]` у `t[i+1]`. Якщо сегмент змінюється в `t[i]`, показання належить новому сегменту. Останній зразок не має наступного кроку й повторює останній сегмент.

Дорога рівна, тож в `ax` немає гравітації. Шум ніколи не змінює `reference`.

## GNSS і втрата сигналу

Фікси припадають на `gnss_offset + k * gnss_period` до кінця поїздки. Позиція у фіксі справжня: генератор бере останній крок IMU не пізніше від фіксу і зсуває його на решту часу. Шум додається зверху.

З типовими налаштуваннями кожен фікс демо-поїздки припадає на крок IMU. Щоб фікси лягли між кроками, задайте `gnss_offset` 0.505.

Фікси з `outage_start <= t < outage_start + outage_duration` пропускаються. Свій шум вони все одно витрачають, тож решта фіксів однакова з втратою і без неї.

## Шум

Нормальні числа виходять із `std::mt19937_64` перетворенням Бокса — Мюллера. Алгоритм `std::normal_distribution` залежить від стандартної бібліотеки, тому її тут немає. `std::log`, `std::sin` і `std::cos` усе ще можуть відрізнятися в останньому біті на різних платформах, тож тести не порівнюють зашумлені значення зі сталими числами.

IMU і GNSS мають окремі генератори. Зміна налаштувань GNSS лишає показання IMU такими, як були.

## Коли результату немає

`GenerateScenario` не кидає власних винятків. Вона повертає `std::nullopt`, коли:

- якесь значення — NaN або нескінченність;
- `imu_dt` або `gnss_period` не додатні;
- тривалість, шум або `gnss_offset` від'ємні;
- сегмент не є цілою кількістю кроків IMU;
- у поїздці понад `kMaxDriveSteps` (1 000 000) кроків або фіксів;
- поїздка не пройшла б `IsWellFormed()`, наприклад коли `gnss_period` такий малий, що два фікси дістають однаковий час.

Повернений сценарій завжди проходить `IsWellFormed()`.

## Демо-поїздка

`DemoDrive()` триває 65 секунд і закінчується біля `(327, 277)`.

| Час, с | Рух |
| --- | --- |
| 0–10 | Розгін з місця до 10 м/с |
| 10–20 | Прямо на схід |
| 20–30 | Поворот на 90° ліворуч, радіус близько 64 м |
| 30–45 | Прямо на північ |
| 45–55 | Поворот на 90° праворуч |
| 55–65 | Гальмування до зупинки, курс на схід |

Типова втрата, 25–40 с, накриває другу половину лівого повороту і пряму після нього. Із 65 фіксів лишається 50.
