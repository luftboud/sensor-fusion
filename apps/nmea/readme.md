GP — talker ID
GP = GPS, GL = ГЛОНАСС, GA = Galileo, GB/BD = BeiDou, GN = комбінований розв'язок
Поля розділені комами. Поля можуть бути порожніми (,,), коли немає фіксу. Це нормальна ситуація, а не помилка.*47 — контрольна сума: XOR усіх байтів між $ і *, записаний двома hex-цифрами.
Максимальна довжина речення — 82 символи разом з $ і \r\n.
Широта має формат ddmm.mmmm, довгота — dddmm.mmmm. S і W дають знак мінус
